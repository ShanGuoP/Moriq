# 设计参考图片

这些 PNG 仅作为历史设计参考保留。程序已停止嵌入和加载本目录照片，便携包也不复制这些文件；实际封面来自用户资源库，空库使用原生控件绘制空状态。

本目录 PNG 来自用户提供的 `docs/UI/` 设计图，仅提取照片、拼贴和头像区域作为界面参考资源。原始参考图没有修改。

原生界面不使用完整截图覆盖窗口；所有按钮、输入、布局和信息区域均由 Iced 控件构成。

重新生成：在项目根目录运行 `cargo run -p moriq-library --example prepare_ui_assets`。

这些图片的来源是用户设计参考，不代表已获得独立照片的商用授权。发布前需要确定授权或替换素材。截图提取素材的分辨率有限，不能替代设计源文件中的高清原图。
