# Moriq 界面与交互设计

## 视觉系统

主色采用雾霾蓝 `#587797`。浅色界面用白色导航与卡片、浅灰蓝工作画布分层；暗色界面使用对应的低亮度表面。主色只突出主操作、当前选择与焦点，辅助信息使用较低对比度的灰蓝。表单分组依靠间距与背景区分，避免多层边框嵌套。

全局按钮、输入框、分组卡片、菜单、滚动条、弹窗和进度条由 `theme.rs` 与 `components.rs` 统一定义。管理、分类、项目、标签、版本、导出、任务、维护和 NAS 面板沿用同一套基础控件与容器。

## 页面组织

| 页面 | 布局与任务 |
| --- | --- |
| 我的资源库 | 封面卡片、资源库信息、独立的打开与管理入口 |
| 资源库首页 | 标题与操作、统计卡片、快捷入口、横向项目封面、收藏及活动信息 |
| 素材工作台 | 标题与视图控制、单行可换行筛选、图片卡片、可收起详情栏 |
| AI 工作室 | 模型管理与安装、模型设置与任务状态、当前整理空间及分类结果 |
| 设置 | 外观与体验、性能与导入、存储与连接分组 |
| NAS | 连接输入卡片、来源卡片、远程浏览与托管下载的用途说明 |

AI 工作室的“模型与设置”以本地模型为主区域，宽窗口右侧使用固定宽度的设置栏，空间不足时自动上下排列。模型卡片按可用宽度切换一列或两列，用途、安装状态、名称、说明、容量与许可分层展示；安装、分析与人脸分组使用主按钮，卸载使用弱化操作。设置、后台任务和运行环境分组呈现，当前任务只展示一次进度与处理数量，失败数量在非零时显示；没有任务时显示明确的空状态。内置人脸模型标记“内置”，模型筛选中的未安装项统一称为“待安装”。

“智能整理”先选择整理空间，再显示人物和整理状态。“重新分析”打开任务选择弹窗，内容分类、标签与描述、人脸分组分别勾选；Qwen 可用时默认选中前两项，人脸分组默认不选。不可用模型和无有效选择时的提交按钮禁用。Qwen 模型卡片只启动两项内容任务；独立人脸入口只启动 CPU 人脸任务。取消弹窗不入队，已有任务保持独立控制。

## 人物卡片与编辑

外层人物分组和人物管理列表共用紧凑卡片：头像、名称与照片数量构成浏览入口，右侧铅笔和垃圾桶为独立按钮，避免嵌套按钮导致误触。图标提供悬停说明；删除使用确认弹窗说明保留照片、文件、标签和版本，确认操作使用危险色。

改名弹窗支持有效名称下按 Enter 保存，空名称不能提交。保存期间禁用重复提交，失败保留输入并在原处提示；取消或返回不提交，从管理列表进入后返回原入口。变更请求绑定资源库、项目、人物和请求编号，过期回执不能覆盖当前弹窗。删除后的人工未归组记录及新照片分组规则见 [AI 工作室与人物整理](AI%20工作室与人物整理.md)。

人物与头像逐步出现，不必等待整批任务结束。普通进度和摘要刷新保留已有头像与在途批次，新人物在当前头像批次完成后补充。人物照片页合并后台刷新，保留当前布局和图片，等新布局和图片页一起就绪后提交，避免处理中反复闪屏。

## 图片浏览与选择

图片卡片以画面为主，常规高度下保留文件名、尺寸与容量信息区；小尺寸卡片保持紧凑。格式标记与更多操作位于画面上，收藏按钮位于信息区。选择以边框和标记反馈，单击选择、双击查看、右键菜单与 Ctrl 多选沿用统一素材身份。

筛选常用格式、标签和评分，其余条件进入“更多筛选”。进入多选后出现选择计数、全选当前页、整理与导出操作。“详情”按钮收起或展开检查栏；切换不会清空当前选择及未保存的备注，图库随可用宽度重新排布。

详情栏使用紧凑标签导航，元数据名称与值分行展示，避免窄窗口中日期和 EXIF 内容被挤成碎片。网格与列表按钮标记当前视图，切回网格保留已有的排布偏好。后台任务分别显示为状态卡片，进度、失败数量、继续或暂停及停止操作保持清晰层级。

## 一致性与验收

所有新交互继续经现有消息与 Service 处理。轻量交互反馈遵守“减少动态效果”设置。诊断构建提供页面与面板截图入口，使用隔离资源库检查首页、图库、选择状态、详情栏、模型、NAS、设置和管理面板；界面测试覆盖双语言、明暗主题、导航回执及草稿保留。

侧栏统一悬停、按压和选中反馈，选中条在布局阶段同步目标位置；选择改变时启动有时限的连续重绘，动画稳定后停止专用帧。人物、分类、项目空间和工作室子页切换参与页面过渡，普通后台摘要更新不重新启动过渡。“减少动态效果”开启时直接显示最终状态。

2026-11-07 的完整检查记录为 340 项测试通过，并单独执行真实 CPU 进程生命周期检查；人物卡片、改名和删除确认使用隔离样例资源库检查。完整动态效果实机复测尚未完成，不能由自动测试推断全部交互都已验收。此前的双语言、明暗主题及 1180 × 740 截图检查属于历史验证，不能替代本轮新增交互的复测。详细范围见 [测试策略](测试策略.md)。
