# AI 工作室与人物整理

> 按 2026-11-07 的 1.2.0 开发更新维护。本文说明当前行为；旧 Qoder 快照中的 Qwen 人脸默认流程不再代表当前界面入口。

## 选择整理范围与分析内容

先打开资源库，再进入“AI 工作室 → 智能整理”选择项目。已有项目的库需要先选择项目；没有项目时可以处理库内全部素材。确认弹窗冻结资源库和项目，切换范围后不能继续提交旧弹窗。

| 入口 | 提交的任务 | 人脸任务是否自动加入 |
|---|---|---|
| 智能整理 → 重新分析 | 弹窗中勾选的内容分类、标签与描述、人脸分组 | 仅在明确勾选时加入，默认不勾选 |
| Qwen 卡片 → 重新分析 | `QwenClassification` 与 `QwenDescription` | 不加入 |
| 人脸分组 | 确认范围后提交 `Analysis(ModelId::Faces)` | 只提交人脸任务 |

不可用模型的选项禁用，没有选中可用任务时不能开始。关闭或取消选择弹窗不提交任务。旧的后台任务不会因为选择其他分析类型而被自动删除；可在后台任务页逐项暂停、继续或停止。

## 两类模型的职责

| 模型 | 本地运行方式 | 安装与用途 |
|---|---|---|
| Qwen3.5-4B | llama.cpp / Vulkan | 权重按需下载，用于媒介、主题分类和标签描述 |
| YuNet + SFace | OpenCV CPU 工作进程 | Windows 完整包内置，用于人脸检测、特征提取和当前项目人物匹配 |

内置人脸组件不需要 Python、CUDA 或单独安装 VC++ 运行库，不能在模型页单独卸载。分组过滤过小或模糊的人脸；自动匹配可能需要人工命名、合并和纠正，不等同于身份核验。

## 识别结果什么时候出现

任务按照片逐项写入结果，完成的部分会随进度刷新，**不需要等待整批结束**。人物摘要与头像是不同的读取请求，分组数量可先出现，头像随后补齐。

普通进度刷新保留在途头像批次，已有头像继续显示；当前批次结束后补充新人物。离开相关页面或切换资源库、项目时才取消旧请求。人物照片页合并后台刷新，旧布局和图像保留到新布局与照片一起就绪，避免先退回固定网格再切回瀑布流。

## 人物卡片、改名与删除

“智能整理”外层卡片和“人物管理”列表共用人物卡片组件：

- 点击头像或名称：进入该人物的照片。
- 点击铅笔：编辑名称，支持有效名称下按 Enter 保存；空名称不能提交。
- 点击垃圾桶：查看删除确认，确认后仅移除分组。
- 取消、关闭或返回：不提交变更；从管理列表打开操作后返回原管理入口。

保存中禁用重复提交；失败在当前弹窗显示错误并保留输入。异步回执校验资源库、项目及请求编号，旧弹窗或其他范围的结果不能覆盖当前操作。

**删除分组保留照片、原文件、标签和版本。** 库层将该人物已有检测置为 `person_id=NULL, manual=1`，再删除人物及其代表向量。对这些人脸的重跑和已领取的任务保留人工取消归组；后来新导入或此前未分析的照片仍可能形成新的人物分组。删除分组不等于移入回收站或永久删除素材。

合并仍使用“人物管理”的来源、目标选择；单张照片的人脸归属可在素材详情中纠正。人物选择、编辑和存储都遵守当前项目范围。

## 整理状态与内容分类

| 显示 | 依据 | 不代表什么 |
|---|---|---|
| 已完成人脸分析 | 当前展示版本存在成功的人脸分析结果，包括成功返回空人脸列表 | 不保证检出人物，也不代表已经完成 Qwen 内容分类 |
| 待整理 | 尚无内容分类且未完成人脸分析的素材 | 不把已经完成人脸分析的照片再次统称为“未分类” |
| 媒介、主题分类 | Qwen 有效分类、人工内容或保留的历史分类 | 不由人脸结果伪造内容类别 |

`Query.face_analyzed` 为可选布尔筛选：`None` 不限制，`Some(true)` 只查看已完成人脸分析的当前版本，`Some(false)` 查看未完成的当前版本。状态卡片和查询使用同一条件，排除回收站和旧展示版本。

## 进程复用与动态效果

“按需加载模型”同时作用于 Qwen 和 CPU 人脸运行器。后台模型批次中复用进程，按需模式下最后一个批次租约释放后卸载；关闭资源库会尝试停止两类运行器。取消或错误路径也释放相应租约。

侧栏提供悬停、按压与选中条反馈，人物、分类、项目空间及工作室子页切换触发过渡。选中目标在布局阶段同步，动效期间主动请求连续重绘，稳定后停止动效专用帧；后台摘要刷新不重启动画。“减少动态效果”开启时直接到达最终状态。

## 验证范围

2026-11-07 本地开发包记录为 340 项测试通过，另有默认跳过的诊断或基准条目；真实 CPU 进程生命周期测试单独执行。成品核对了 50 个运行组件，并以空白图片验证 CPU 工作进程能正常返回。该结果不构成人脸识别质量、真实 NAS、清洁系统安装或公开发布验收。

人物卡片、改名和删除确认进行过隔离样例界面检查；界面控制停止后，完整动态效果实机复测未继续。该包未签名且 `PublicRelease=false`，不等同于已公开发布版本。后续检查以实际测试输出和发布记录为准。
