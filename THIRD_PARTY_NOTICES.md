Upstream revision: https://github.com/FFmpeg/FFmpeg/tree/46d899d7a0 . Build recipes: https://github.com/BtbN/FFmpeg-Builds . A reproducible corresponding-source bundle including enabled dependencies must be archived before public release.

Model weights are optional downloads initiated by the user, and are not included in the portable package. workers/ai/models.json pins each model revision, file size and SHA-256. Model source links and license names appear in the model manager. Each downloaded model includes its upstream license where supplied. Qwen3.5-4B uses the pinned Unsloth Q4_K_M GGUF and F16 vision component listed in the registry (Apache-2.0). Model predictions require user review.

Moriq Space's FFmpeg integration and resource-guard source is under crates/moriq-library/native. Dynamic libraries remain replaceable within their compatible ABI. This application does not require removal of third-party copyright notices or restrict rights granted by their licenses.
