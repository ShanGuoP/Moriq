# Moriq Space · 墨屿

给照片、参考图和创作素材一个安静的本地空间。

Moriq Space（中文名：墨屿）是一款本地桌面素材管理工具。你可以把分散的图片和视频收进独立资源库，用项目、标签、评分和智能集合整理，再按需要查找、查看、精修或导出。

**当前源码版本为 1.2.0，支持 Windows x86_64、简体中文、英文和浅色、暗色主题。** 已发布的便携包版本以 [Releases](https://github.com/ShanGuoP/Moriq/releases/latest) 为准，完整解压后即可使用。本地 AI 与 Synco 联动请先用少量素材试用，具体操作见下文。

本文已同步到 **2026-11-07 开发更新**：分析内容可分别选择，人物卡片支持改名和删除分组，人脸分析状态独立显示。开发便携包不等同于公开发布版本；详细操作和实现说明见 [AI 工作室与人物整理](repowiki/AI%20工作室与人物整理.md)与 [项目 Wiki](repowiki/INDEX.md)。

首次打开旧资源库时会自动备份数据库并升级整理结构。升级到 1.2.0 的资源库后，请继续使用 1.2.0 或后续兼容版本；旧程序无法打开升级后的资源库，原片不受升级影响。

## 可以用它做什么

| 你的需求 | Moriq Space 提供的功能 |
|---|---|
| 收集创作参考 | 文件、文件夹和拖放导入；支持托管导入与外部引用；相同内容自动去重 |
| 按工作整理 | 项目及子项目、标签、收藏、评分、备注、虚拟分组、多字段批量编辑 |
| 找回需要的素材 | 文件名、标签、备注搜索；日期、格式、尺寸、颜色、评分等筛选；保存为动态智能集合 |
| 快速浏览与挑片 | 瀑布流、固定网格、列表；图片放大、缩放和平移；版本切换与并排对比 |
| 整理照片信息 | 查看 EXIF 与 GPS、按元数据检索、补充地点、打开地图 |
| 找出相近图片 | 建立相似图片索引，查找缩放、压缩等视觉近似版本，结果由你判断 |
| 交付素材 | 原文件导出，或转换图片格式、调整尺寸、旋转；可附带整理信息和 EXIF |
| 维护素材库 | 回收站、库外备份、独立克隆、迁移副本、完整性检查、空间统计与预览缓存清理 |
| 尝试本地 AI | 按需安装 Qwen3.5-4B 生成分类、标签与描述；使用内置 YuNet + SFace 按人物整理 |
| 连接精修流程 | 将图片发送到兼容的 Synco，回传结果作为新版本保存，保留原片 |

日常整理、版本切换和转换导出不会覆盖原片。**确认永久删除时，相关托管原片和库内版本会被删除；外部引用的原文件保留。**

## 开始使用

### 1. 打开程序，创建资源库

从旧版升级时，已有资源库、模型和设置会继续沿用，无需重新导入素材或下载模型。模型和日志目录仍使用原来的 `MORIQ` 文件夹名。

使用 Windows 便携包时，请先完整解压，再运行包内的 `Moriq Space.exe`。保留同目录的 `codecs`、`ai` 等配套文件夹，避免因单独移动 EXE 导致视频或 AI 组件缺失。

首次打开时选择新建资源库，填写名称并选择保存位置。Moriq Space 会创建一个以 `.moriq` 结尾的文件夹。

打开已有库时，选择整个 `.moriq` **文件夹**，无需进入内部选择数据库文件。你可以创建多个库，按工作、个人照片或不同项目分别管理；每次使用一个活动库。

已有资源库记录时，首页直接展示已登记资源库的封面和名称，点击即可打开。同名库可通过路径区分；尚未登记的库，使用“打开已有资源库”添加。

点击右上角的设置图标，可在“界面语言”中选择简体中文或 English，在“外观主题”中切换浅色、暗色。选择立即生效并自动保存，重启后继续使用；文件名、自定义标签和项目名称保持原文。

### 2. 导入图片或文件夹

打开资源库后，点击顶部“导入”，或将多张图片、文件夹一起拖入窗口，看到提示后释放。需要按项目整理时，先创建或进入对应项目。拖放采用托管导入，原文件保留；导入过程中继续拖入的文件会排队，“停止导入”也会清空等待队列。

| 导入方式 | 适合的情况 | 原文件在哪里 |
|---|---|---|
| 托管导入 | 希望资源库集中保管素材，方便整体备份或移动 | 库内保存一份原片，外部来源文件保留 |
| 外部引用 | 已有固定目录、外置硬盘或较大的原片集合，希望沿用原有位置 | 原片留在原目录，资源库记录位置并保存预览及整理信息 |
| NAS 远程浏览 | Windows SMB 共享目录中的图片，希望先整理再决定是否下载 | 原片保留在 NAS，库内保存缩略图与整理信息，按需缓存清晰预览 |

托管导入会按项目保留来源文件夹和原文件名，同名的不同内容会自动避让；同一项目中完全相同的内容会去重。如果相同素材已在回收站，重新导入会将它恢复。同一图片加入不同项目时，会分别保存独立副本，收藏、标签、版本和删除操作互不影响。大文件夹会边扫描边导入，可以查看进度并停止；设置中可调整导入并发和内存预算。

“同时处理上限”是并发上限，“图片处理内存 · MiB”是整批处理的内存预算。实际解码数量同时受这两项限制；设置保存后在下次导入生效。状态栏会显示当前解码数、实际上限、峰值和等待内存的数量，设置中可查看当前批次的单张最高内存估算。

### 界面与导航

界面采用雾霾蓝主色，侧栏提供“我的资源库”“素材工作台”“AI 工作室”和远程来源入口。图库卡片展示图片、文件名、尺寸和容量；筛选集中在工具栏，进入多选后显示批量整理与导出操作。“详情”按钮可以收起检查栏扩大浏览空间，切换时保留当前选择与未保存备注。首页使用横向项目封面和统计卡片；设置按外观、性能、存储分组，支持浅色与暗色主题。

### 连接 NAS 图片

在 Windows 中先确保 SMB 共享可访问；如需账号密码，请在 Windows 中建立连接或保存凭据。Moriq 的“导入 → NAS 图片”输入 `\\服务器\共享目录` 并连接。选择共享目录内的文件夹后，可以“远程浏览并登记”，也可以“下载文件夹到本地”。请通过局域网或 VPN 访问 SMB 共享。

远程登记时会生成本地缩略图和整理记录；打开图片后，清晰预览会按需缓存在本地。打开原图、导出或重建已清理的缓存时需要 NAS 在线。离线时可查看已有缓存，远程原片不包含在资源库备份中。选中已登记的 NAS 图片，在素材菜单选择“下载 NAS 原片到资源库”，可校验并转为托管原片，保留标签、项目和版本身份；此后可以离线使用，并包含在资源库备份中。下载中断或 NAS 文件变化会报告失败，不会将不完整文件当作原片。

本版仅支持 Windows SMB；WebDAV 尚未接入。大目录首次登记需要逐张读取以生成缩略图，速度取决于 NAS 和网络。NAS 地址在资源库中保存，凭据由 Windows 管理。

新配置默认使用 2048 MiB 导入预算，已有手动设置保留。超高像素 RAW 仍可能超过解码器自身的上限。

### 3. 浏览、挑选和整理

- 在瀑布流、固定网格和列表之间切换，调整缩略图大小。
- 单击素材查看详情；双击图片放大，滚轮缩放，鼠标平移。
- 右键或点击卡片上的“…”打开素材操作菜单；按住 Ctrl 单击可多选，右键已选素材可批量操作。
- 在素材菜单选择“设为资源库封面”，使用当前版本生成独立封面，资源库首页与卡片同步更新；重启后保留，不修改原片。回收站素材不可设为封面。
- 使用收藏、评分、标签、备注和项目归属整理素材；多选后可批量修改。
- 项目支持父子层级；虚拟分组可以引用同一份素材，便于按不同主题归类。
- 查看大图后关闭，会回到原来的图库位置和选择；返回按钮也可返回此前的页面或面板入口。
- 播放视频时，离开素材页会停止播放；再次打开视频即可继续查看。

侧栏提供选中条形变、悬停与按压反馈；页面、人物筛选、项目空间及工作室子页切换提供轻量过渡。连续操作会从当前状态衔接，后台摘要刷新不重启动画；“减少动态效果”开启时直接切换状态。

打开图片时会先读取清晰预览，放大后再按需读取原图区域。托管素材的预览会缓存在库内，重新打开可复用；首次读取 RAW 仍需要解码。需要检查细节时，点击“100%”；需要查看整张图片时，点击“适应窗口”。

### 4. 搜索并保存常用条件

顶部搜索框用于查找**文件名、标签和备注**。查找某个标签时，可直接选择精确标签；需要组合条件时，打开筛选或组合规则。

例如，可以把“高评分、某种格式、指定日期范围、未归类项目”等条件保存为**智能集合**。它保存的是筛选规则，符合条件的素材会随库内内容变化自动更新。

EXIF/GPS 检索使用独立入口。普通文字搜索包含已生成的 AI 标签和描述，无需加载模型。

筛选中可以分别选择媒介和多个主题，多个主题按“同时满足”查找。AI 标签自动出现在普通标签栏，以 `AI` 标记来源；支持精确标签筛选和智能集合。一两个中文字同样可以搜索，重新分析后不再沿用被替换的旧标签和描述。

在素材详情的 AI 卡片中，可保存人工媒介、主题和描述，人工内容不会被重新分析覆盖，备注保持独立。AI 标签可移除或保留为人工标签；移除后同一版本不会被再次自动加回，也可主动重置拒绝记录。导出的整理信息包含当前有效内容。

在“智能整理 → 自定义分类”中，可新增主题、修改名称和识别说明、调整顺序，以及禁用或恢复分类。“参与识别并显示在卡片和侧栏”关闭后，该媒介或主题不再进入新识别的提示和允许输出范围，同时隐藏入口；已有识别记录、原片和人工内容保留。保存后生效，旧分类任务停止，已有结果会提示待更新，由你主动重新整理。未匹配任何启用媒介时保留未分配，不强行归到其他类别；全部分类禁用时不调用模型进行分类。改名和排序不丢失原有素材关联，固定媒介的内部 ID 不变。

模型筛选页签从左到右为“全部模型、待安装、已安装”。

自定义分类可“保存为模板”，新建资源库自动沿用。已有资源库可“套用已存模板”到编辑草稿，再保存并同步；本库独有分类保留为禁用状态，不参与新识别，不删除素材关联。模板保存在本机设置中，重启后仍可复用。

AI 模型页提供“暂停全部 / 继续任务 / 完全停止”，后台任务页也可逐项控制。暂停会中断当前模型推理，继续时重做尚未完成的素材；完全停止不会自动恢复，已完成结果保留。

分类设置采用分栏编辑，识别说明支持多行输入；素材详情中的 AI 识别提供可换行主题选择、多行描述，以及带悬停提示的标签保留/移除操作。详情页签文字在各自区域居中。

### 5. 导出需要的素材

选择一张或多张素材，在操作菜单中选择导出，设置格式和参数，再选择资源库之外的保存位置。

- **原文件**：用于保留源格式和内容；视频目前使用这一方式导出。
- **图片转换**：支持 JPEG、PNG、无损 WebP、TIFF 和 BMP。
- 可设置最长边、旋转角度和重采样方式；JPEG 可调整质量，透明区域使用白底。
- 最长边为 `0` 表示不缩放。原文件模式配合缩放或旋转时，图片会转换为 PNG。
- 指定缩放尺寸的最长边上限为 8192 像素；选择 `0` 时仍可按格式能力进行原尺寸导出。
- 可按格式、导入日期或目录模板组织导出，并附带标签、备注等整理信息 JSON。
- 选择保留 EXIF 时，JPEG/PNG/WebP 嵌入元数据，其他转换格式可附带 `.exif` 文件；转换图片按 sRGB 输出。

输出会保存到一个新的导出目录，原片保持不变。超大图片建议指定适合交付的最长边，部分解码器仍受内存预算和格式兼容性限制。

## 支持哪些素材

| 类型 | 当前支持范围与说明 |
|---|---|
| 常见图片 | JPEG、PNG、WebP、BMP、TIFF；GIF 按首帧作为静态素材查看 |
| SVG | 本地渲染；不加载外部链接图像资源 |
| 相机 RAW | 包含 DNG、CR2/CR3、NEF、ARW、RW2、RAF 等格式入口；Windows 完整运行包提供 RAW 读取组件，具体兼容性取决于相机及压缩方式 |
| HEIC / HEIF / AVIF | Windows 下取决于可用的系统解码器，必要时需安装相应编解码扩展 |
| 视频 | MP4、MOV、M4V、MKV、WebM、AVI、MTS、M2TS；Windows 完整运行包提供预览和播放组件，具体编码支持取决于解码器 |

文件扩展名被识别，不保证所有编码变体都能解码。当前不提供 PDF、PSD/PSB 素材支持；显示器 ICC/HDR 的完整色彩管理仍未完成。

## 本地 AI：按需开启

日常导入、整理和普通搜索不需要下载 AI 模型。侧栏“AI 工作室”分为“智能整理”和“模型与设置”：

1. 无需先打开资源库，就可以查看模型用途、大小和许可证，安装、暂停、继续或卸载模型。
2. 需要分析素材时，在左侧选择资源库，再选择要整理的项目。已有项目的库需要先进入项目；没有项目时可处理库内全部素材。切库后仍停留在 AI 工作室，全局模型和下载任务保留。
3. 在“智能整理”点击“重新分析”，分别勾选**内容分类、标签与描述、人脸分组**，确认后仅运行选中部分。不可用的模型对应项会禁用；人脸分组默认不勾选。
4. Qwen 模型卡片上的“重新分析”只新建内容分类和标签描述任务；“人脸分组”入口只启动 CPU 人脸任务。此前已经排队的人脸任务独立运行，可在后台任务中单独暂停或停止。
5. 在人物、内容分类卡片、普通搜索或素材详情中查看结果。结果按照片逐项保存，人物及头像会陆续出现，不需要等待整批识别完成。

打开包含外部引用的库时，库内自动读取任务先暂停，可核对来源后在任务中继续。普通网络或设备引用不会自动读取；通过 NAS 面板明确连接的 SMB 目录可以远程读取。

内容分类卡片使用当前整理空间中对应素材的真实缩略图。人脸分析成功的照片单独显示为“已完成人脸分析”，不再计入“待整理”；成功分析但未检出清晰人脸的照片同样属于已完成。这个状态不代表已经完成 Qwen 内容分类，也不保证每张照片都有人物分组。

分析进度更新时，人物与分类数量会逐步刷新；人物照片列表保留当前画面，等新布局与照片就绪后一起更新，避免反复切换布局。头像加载在普通轮询期间继续进行，离开相关页面或切换资源库、项目时取消旧请求。

“智能整理”的人物卡片和“人物管理”列表均提供独立的改名、删除按钮。点击头像或名称进入该人物的照片；点击铅笔改名，保存后同步更新列表；点击垃圾桶会先显示删除确认。取消、关闭弹窗或返回不会提交改名或删除。

**删除人物分组只取消归组，不会删除照片、原文件、标签或版本。** 已有分组的人脸会保留人工取消归组记录，重跑这些照片时不自动恢复该分组；后来新导入或尚未分析的照片仍可能形成新分组。需要合并时，在“人物管理”中选择来源和目标；单张图片的人脸归属可在详情中纠正。

### 模型下载源与设置

“模型设置”中的“国内下载加速”默认开启，使用 [HF-Mirror](https://hf-mirror.com/) 下载；关闭后使用 Hugging Face 原站。切换源在下次安装或继续时生效，保留已有下载断点。遇到限流或临时服务错误时会有限重试；仍然失败时，可暂停后切换源，再继续下载。镜像和权重下载服务的可达性取决于网络环境。

两种下载源提供相同版本的模型，安装时会检查下载文件是否完整。模型目录与资源库分开；Windows 默认位于 `%APPDATA%\MORIQ\models`，切换资源库无需重复安装。

需要查看下载的文件时，打开顶部“设置”，在“模型与索引”中点击“打开模型文件夹”。尚未创建资源库时也可以使用此按钮。

“按需加载模型”控制闲置时是否释放模型，不控制下载。Qwen 与 CPU 人脸运行器在后台模型批次内复用，按需模式下批次结束后释放，关闭资源库也会尝试停止运行器。“卸载模型后保留索引”控制可卸载模型的索引保留策略；内置 CPU 人脸组件不提供单独卸载。

### 当前提供的模型

| 模型能力 | 用途 | 获取方式 |
|---|---|---|
| Qwen3.5-4B | 图片媒介与主题分类、中文标签和描述 | 主动下载，通过本地 llama.cpp 运行 |
| YuNet + SFace · CPU | 清晰人脸检测、特征提取和人物分组 | Windows 完整便携包内置，离线运行 |

Qwen 权重不随便携包预装；内容分类与标签描述分别排队，可在后台任务中查看进度或重试失败项。

Windows 便携包包含 OpenCV 4.12、两个 ONNX 人脸模型和所需运行库，无需 Python、CUDA 或另装 VC++ 安装包。点击“人脸分组”，确认整理范围后开始后台处理；过小、模糊的人脸会被过滤，分组只匹配当前项目中的人物。重跑时更新旧自动结果，保留人工命名、合并、纠正及取消归组记录。语义向量检索尚未恢复；普通内容搜索和近似图片查找仍可使用。

后台任务会保留历史失败记录。重试后，请查看新任务的结果；旧任务的错误记录不会因新任务成功而自动清空。

## 使用 Synco 精修

选中图片，在素材操作中选择“发送到 Synco 精修”。你需要安装具有兼容交接接口的 Synco，并在相关设置中指定程序位置或先启动它。

Moriq Space 会准备交接副本；收到精修结果后，保存为该素材的新版本。原片保留，你可以在版本页切换展示版本，或并排比较两个版本。

当前以 Windows 同机联动为主。使用重要素材前，请先用副本完成一次发送、精修和回传，确认你的 Synco 版本与工作流兼容。

## 备份、移动和清理

**资源库备份**可从资源库工具中的维护入口进行，保存位置应在当前库之外。外部引用的原片不包含在库备份中，需要另外备份；AI 模型安装目录也与资源库分开。

打开需要升级的旧版本资源库时，程序会先自动备份数据库，再进行升级；可在通知中查看备份位置。数据库备份不包含原片，不能代替完整资源库备份。

需要整体搬迁时，关闭应用后移动整个 `.moriq` 文件夹，再从新位置打开。使用内置“创建迁移副本”会保留资源库身份和原库；希望两份库分别使用时，选择“创建独立克隆”。外部引用文件仍需单独迁移或重新关联。

| 操作 | 会发生什么 |
|---|---|
| 移入回收站 | 素材暂时退出正常浏览，可恢复 |
| 永久删除 / 清空回收站 | 确认后删除对应托管原片和库内版本，无法通过回收站恢复；外部引用原片保留 |
| 永久删除项目 | 按确认范围清理项目及子项目的独占素材；其他项目共享的素材保留 |
| 删除人物分组 | 取消人物归组并保留人工记录，照片、文件、标签及版本保留 |
| 预览缓存清理 | 清理可再生成的预览，后续查看时重新生成 |
| 孤儿文件清理 | 先扫描并隔离符合条件的未登记文件，可恢复；永久清理隔离区需要再次确认 |

完整性检查可以查找缺失或损坏文件；空间面板可查看实际占用。外置硬盘盘符或目录改变时，可尝试重新定位原片，或按旧、新目录校验后重新关联。

后台任务入口可查看任务进度、失败素材，并对支持的任务进行暂停、继续、取消或仅重试失败项。持久任务可在重开库后继续；导入、维护和 Synco 的停止及恢复方式以各自面板为准。

## 常见问题

**素材存在哪里？**

托管原片、版本和整理信息保存在你选择的 `.moriq` 文件夹中；外部引用原片留在原目录。最近打开列表和应用设置保存在系统用户目录，模型包单独安装。

**需要上传照片吗？**

日常整理和已安装模型的推理在本机完成。下载模型需要联网；发送到 Synco 会把交接副本交给兼容的本机程序；打开地图会调用外部地图服务。

**便携包里的文件可以删除吗？**

“我的资源库”中，每张卡片下可打开“管理资源库”。“从列表移除”仅忘记本机记录，不删除文件；“永久删除”需要再次输入完整库名，会删除库目录内的托管原片、版本与索引，库外引用原片不受影响。被其他窗口/任务锁定、身份不一致、包含链接或嵌套资源库的目录会拒绝删除。删除失败时请按错误提示检查剩余文件路径，不代表已完整删除。

打包脚本按项目版本生成 `Moriq-Space-Windows-v<版本号>.zip`，校验清单同步使用该文件名。

便携包根目录仅保留 `Moriq Space.exe`、`ai` 和 `codecs`，不附带独立的许可、版权说明文件或目录。相关资料与构建、审计报告保存在包外，运行组件目录内保留对应许可说明。请保留完整的解压目录。`codecs` 提供 RAW、视频等媒体组件，`ai` 提供本地模型的运行组件；只保留 `Moriq Space.exe` 会导致相关功能不可用。Qwen 权重由你另外安装，可在模型页卸载以腾出空间；CPU 人脸模型随完整包内置，不能单独卸载。

**为什么资源库占用与图片大小之和不同？**

版本、交接副本和预览会产生额外占用，共享内容可能通过硬链接减少实际磁盘占用。外部引用登记量也不等于库内占用，以空间面板的分类统计为准。

**图片打不开或视频无法播放怎么办？**

先确认源文件存在、便携包完整，必要的系统解码器已安装。部分相机 RAW、视频编码和超大媒体仍可能不受支持；保留原文件，并记录格式和错误提示以便反馈。

**导入并发设为 10，为什么没有同时处理 10 张？每张都要预留 1024 MiB 吗？**

10 是处理上限，不保证同时解码 10 张。RAW 会先探测元数据，再按尺寸和解码所需缓冲区估算内存，不再每张固定预留 1024 MiB；普通图片也受内存预算约束，视频及部分无法估算的路径仍使用保守预算。大图可能降低实际并发，可结合状态栏峰值、等待内存数和设置中的单张估算判断。

**模型下载失败怎么办？**

在 AI 页“模型设置”中确认下载源。默认使用国内镜像；如该源不可达，可暂停下载、切换“国内下载加速”开关，再点击继续。切换源不需要重建资源库，完整性校验失败的文件需要重新下载。

**能直接管理十万张照片吗？**

大批量导入前，请先备份素材，再分批导入。可以先导入一部分，确认浏览、搜索和导出符合需要后继续；实际速度取决于硬盘、素材尺寸和可用内存。

## 使用范围与反馈

当前建议在 Windows 上使用。部分相机 RAW、视频编码和显卡可能不兼容；遇到问题时，请保留原片，先用少量副本尝试对应功能。

遇到问题，可在[项目仓库](https://github.com/ShanGuoP/Moriq)反馈。请附上系统版本、操作步骤、素材格式和错误信息。诊断日志默认关闭；在设置中开启并重启后，Windows 日志位于 `%LOCALAPPDATA%\MORIQ\logs\desktop.log`。开启后的日志可能包含文件名和路径，分享前请检查内容。
