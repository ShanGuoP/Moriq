# Moriq Space · 墨屿

给照片、参考图和创作素材一个安静的本地空间。

Moriq Space（中文名：墨屿）是一款本地桌面素材管理工具。你可以把分散的图片和视频收进独立资源库，用项目、标签、评分和智能集合整理，再按需要查找、查看、精修或导出。

**当前为 0.1 开发版，提供 Windows x86_64 运行包，支持简体中文、英文和浅色、暗色主题。** 你可以导入、整理、浏览和导出素材；本地 AI 与 Synco 联动请先用少量素材试用，具体操作见下文。

## 可以用它做什么

| 你的需求 | Moriq Space 提供的功能 |
|---|---|
| 收集创作参考 | 文件、文件夹和拖放导入；支持托管导入与外部引用；相同内容自动去重 |
| 按工作整理 | 项目及子项目、标签、收藏、评分、备注、虚拟分组、多字段批量编辑 |
| 找回需要的素材 | 文件名、标签、备注搜索；日期、格式、尺寸、颜色、评分等筛选；保存为动态智能集合 |
| 快速浏览与挑片 | 瀑布流、固定网格、列表；图片放大、缩放和平移；版本切换与并排对比 |
| 整理照片信息 | 查看 EXIF 与 GPS、按元数据检索、补充地点、打开地图 |
| 找出相近图片 | 建立相似图片索引，查找缩放、压缩等视觉近似版本，结果由你判断 |
| 交付素材 | 原文件导出，或转换图片格式、调整尺寸、旋转；可附带整理信息和 EXIF |
| 维护素材库 | 回收站、库外备份、独立克隆、迁移副本、完整性检查、空间统计与预览缓存清理 |
| 尝试本地 AI | 按需安装模型，进行分类、语义检索、描述、OCR、物体或人脸分析；需要先安装模型并建立相应索引 |
| 连接精修流程 | 将图片发送到兼容的 Synco，回传结果作为新版本保存，保留原片 |

日常整理、版本切换和转换导出不会覆盖原片。**确认永久删除时，相关托管原片和库内版本会被删除；外部引用的原文件保留。**

## 开始使用

### 1. 打开程序，创建资源库

从旧版升级时，已有资源库、模型和设置会继续沿用，无需重新导入素材或下载模型。模型和日志目录仍使用原来的 `MORIQ` 文件夹名。

使用 Windows 便携包时，请先完整解压，再运行包内的 `Moriq Space.exe`。保留同目录的 `codecs`、`ai` 等配套文件夹，避免因单独移动 EXE 导致视频或 AI 组件缺失。

首次打开时选择新建资源库，填写名称并选择保存位置。Moriq Space 会创建一个以 `.moriq` 结尾的文件夹。

打开已有库时，选择整个 `.moriq` **文件夹**，无需进入内部选择数据库文件。你可以创建多个库，按工作、个人照片或不同项目分别管理；每次使用一个活动库。

已有资源库记录时，首页直接展示已登记资源库的封面和名称，点击即可打开。同名库可通过路径区分；尚未登记的库，使用“打开已有资源库”添加。

点击右上角的设置图标，可在“界面语言”中选择简体中文或 English，在“外观主题”中切换浅色、暗色。选择立即生效并自动保存，重启后继续使用；文件名、自定义标签和项目名称保持原文。

### 2. 导入图片或文件夹

点击顶部“导入”，或把文件、文件夹拖入窗口。需要按项目整理时，先创建或进入对应项目。

| 导入方式 | 适合的情况 | 原文件在哪里 |
|---|---|---|
| 托管导入 | 希望资源库集中保管素材，方便整体备份或移动 | 库内保存一份原片，外部来源文件保留 |
| 外部引用 | 已有固定目录、外置硬盘或较大的原片集合，希望沿用原有位置 | 原片留在原目录，资源库记录位置并保存预览及整理信息 |

托管导入会按项目保留来源文件夹和原文件名，同名的不同内容会自动避让；完全相同的内容会去重。如果相同素材已在回收站，重新导入会将它恢复。大文件夹会边扫描边导入，可以查看进度并停止；设置中可调整导入并发和内存预算。

“同时处理上限”是并发上限，“图片处理内存 · MiB”是整批处理的内存预算。实际解码数量同时受这两项限制；设置保存后在下次导入生效。状态栏会显示当前解码数、实际上限、峰值和等待内存的数量，设置中可查看当前批次的单张最高内存估算。

新配置默认使用 2048 MiB 导入预算，已有手动设置保留。超高像素 RAW 仍可能超过解码器自身的上限。

### 3. 浏览、挑选和整理

- 在瀑布流、固定网格和列表之间切换，调整缩略图大小。
- 单击素材查看详情；双击图片放大，滚轮缩放，鼠标平移。
- 右键或点击卡片上的“…”打开素材操作菜单。
- 使用收藏、评分、标签、备注和项目归属整理素材；多选后可批量修改。
- 项目支持父子层级；虚拟分组可以引用同一份素材，便于按不同主题归类。
- 查看大图后关闭，会回到原来的图库位置和选择；返回按钮也可返回此前的页面或面板入口。
- 播放视频时，离开素材页会停止播放；再次打开视频即可继续查看。

页面切换、弹窗和菜单提供轻量过渡；连续切换时可打断尚未完成的跳转。

打开图片时会先读取清晰预览，放大后再按需读取原图区域。托管素材的预览会缓存在库内，重新打开可复用；首次读取 RAW 仍需要解码。需要检查细节时，点击“100%”；需要查看整张图片时，点击“适应窗口”。

### 4. 搜索并保存常用条件

顶部搜索框用于查找**文件名、标签和备注**。查找某个标签时，可直接选择精确标签；需要组合条件时，打开筛选或组合规则。

例如，可以把“高评分、某种格式、指定日期范围、未归类项目”等条件保存为**智能集合**。它保存的是筛选规则，符合条件的素材会随库内内容变化自动更新。

EXIF/GPS 检索和 AI 语义搜索使用各自入口。AI 自然语言搜索需要先安装对应模型并建立索引，普通文字搜索无需模型。

### 5. 导出需要的素材

选择一张或多张素材，在操作菜单中选择导出，设置格式和参数，再选择资源库之外的保存位置。

- **原文件**：用于保留源格式和内容；视频目前使用这一方式导出。
- **图片转换**：支持 JPEG、PNG、无损 WebP、TIFF 和 BMP。
- 可设置最长边、旋转角度和重采样方式；JPEG 可调整质量，透明区域使用白底。
- 最长边为 `0` 表示不缩放。原文件模式配合缩放或旋转时，图片会转换为 PNG。
- 指定缩放尺寸的最长边上限为 8192 像素；选择 `0` 时仍可按格式能力进行原尺寸导出。
- 可按格式、导入日期或目录模板组织导出，并附带标签、备注等整理信息 JSON。
- 选择保留 EXIF 时，JPEG/PNG/WebP 嵌入元数据，其他转换格式可附带 `.exif` 文件；转换图片按 sRGB 输出。

输出会保存到一个新的导出目录，原片保持不变。超大图片建议指定适合交付的最长边，部分解码器仍受内存预算和格式兼容性限制。

## 支持哪些素材

| 类型 | 当前支持范围与说明 |
|---|---|
| 常见图片 | JPEG、PNG、WebP、BMP、TIFF；GIF 按首帧作为静态素材查看 |
| SVG | 本地渲染；不加载外部链接图像资源 |
| 相机 RAW | 包含 DNG、CR2/CR3、NEF、ARW、RW2、RAF 等格式入口；Windows 完整运行包提供 RAW 读取组件，具体兼容性取决于相机及压缩方式 |
| HEIC / HEIF / AVIF | Windows 下取决于可用的系统解码器，必要时需安装相应编解码扩展 |
| 视频 | MP4、MOV、M4V、MKV、WebM、AVI、MTS、M2TS；Windows 完整运行包提供预览和播放组件，具体编码支持取决于解码器 |

文件扩展名被识别，不保证所有编码变体都能解码。当前不提供 PDF、PSD/PSB 素材支持；显示器 ICC/HDR 的完整色彩管理仍未完成。

## 本地 AI：按需开启

日常导入、整理和普通搜索不需要安装 AI 模型。需要时，从侧栏“AI 模型”进入模型管理：

1. 无需先打开资源库，就可以查看模型用途、大小和许可证，安装、暂停、继续或卸载模型。
2. 需要分析素材时，直接在 AI 页左侧选择资源库。列表展示所有已登记库的封面、名称和路径，并标明当前库；切换后仍停留在 AI 页，全局模型和下载任务保留。
3. 安装完成后，运行相应的全库分析或索引任务。
4. 在分类、语义搜索或素材详情的“AI 识别”“相似推荐”等入口查看结果。

打开包含外部引用的库时，库内自动读取任务先暂停，可核对来源后在任务中继续。网络或设备路径不会自动读取；这类素材需要先复制到本地再重新关联。

AI 页的人像、风景、建筑、插画、截图和未分类卡片使用当前库中对应分类的真实素材缩略图。没有素材时显示空状态，切库后同步更新；不会使用示例拼图代替实际内容。

分析进度更新时，分类数量、封面和当前分类图库会自动刷新。资源库侧栏的人像、风景等入口显示真实分类数量，点击直接查看对应素材。

侧栏只列出当前库中已有结果的分类，名称和数量随识别及人工纠正更新。点击“人脸识别”可查看人物列表，名称前的人脸缩略图帮助区分未命名人物；点击人物查看对应素材。需要改名或合并时，在列表上方选择人物后操作；单张图片的人脸归属可在详情中纠正。

### 模型下载源与设置

“模型设置”中的“国内下载加速”默认开启，使用 [HF-Mirror](https://hf-mirror.com/) 下载；关闭后使用 Hugging Face 原站。切换源在下次安装或继续时生效，保留已有下载断点。遇到限流或临时服务错误时会有限重试；仍然失败时，可暂停后切换源，再继续下载。镜像和权重下载服务的可达性取决于网络环境。

两种下载源提供相同版本的模型，安装时会检查下载文件是否完整。模型目录与资源库分开；Windows 默认位于 `%APPDATA%\MORIQ\models`，切换资源库无需重复安装。

需要查看下载的文件时，打开顶部“设置”，在“模型与索引”中点击“打开模型文件夹”。尚未创建资源库时也可以使用此按钮。

“按需加载模型”控制闲置时是否释放模型，不控制下载；“卸载模型后保留索引”控制卸载后的索引保留策略。

### 当前提供的模型

| 模型能力 | 用途 |
|---|---|
| Chinese-CLIP | 图片分类、中文语义检索及内容相似推荐 |
| Florence-2 | 图片描述、文字识别与物体识别 |
| YuNet + SFace | 人脸检测、人物分组，并提供人工改名、合并和纠正入口 |

模型由你主动下载，不随便携包预装；模型推理在本机进行。卸载前可选择是否保留已经生成的分析结果与索引。模型效果需要人工核对，人脸分组和近似推荐不会替你自动删除素材。

三个模型可按需独立安装，无需按固定顺序使用。需要分类和中文语义搜索时选择 Chinese-CLIP，需要描述或识别文字时选择 Florence-2，需要整理人物时选择 YuNet + SFace。分析失败时，可从后台任务中查看失败素材，并仅重试失败项。

后台任务会保留历史失败记录。重试后，请查看新任务的结果；旧任务的错误记录不会因新任务成功而自动清空。

## 使用 Synco 精修

选中图片，在素材操作中选择“发送到 Synco 精修”。你需要安装具有兼容交接接口的 Synco，并在相关设置中指定程序位置或先启动它。

Moriq Space 会准备交接副本；收到精修结果后，保存为该素材的新版本。原片保留，你可以在版本页切换展示版本，或并排比较两个版本。

当前以 Windows 同机联动为主。使用重要素材前，请先用副本完成一次发送、精修和回传，确认你的 Synco 版本与工作流兼容。

## 备份、移动和清理

**资源库备份**可从资源库工具中的维护入口进行，保存位置应在当前库之外。外部引用的原片不包含在库备份中，需要另外备份；AI 模型安装目录也与资源库分开。

打开需要升级的旧版本资源库时，程序会先自动备份数据库，再进行升级；可在通知中查看备份位置。数据库备份不包含原片，不能代替完整资源库备份。

需要整体搬迁时，关闭应用后移动整个 `.moriq` 文件夹，再从新位置打开。使用内置“创建迁移副本”会保留资源库身份和原库；希望两份库分别使用时，选择“创建独立克隆”。外部引用文件仍需单独迁移或重新关联。

| 操作 | 会发生什么 |
|---|---|
| 移入回收站 | 素材暂时退出正常浏览，可恢复 |
| 永久删除 / 清空回收站 | 确认后删除对应托管原片和库内版本，无法通过回收站恢复；外部引用原片保留 |
| 永久删除项目 | 按确认范围清理项目及子项目的独占素材；其他项目共享的素材保留 |
| 预览缓存清理 | 清理可再生成的预览，后续查看时重新生成 |
| 孤儿文件清理 | 先扫描并隔离符合条件的未登记文件，可恢复；永久清理隔离区需要再次确认 |

完整性检查可以查找缺失或损坏文件；空间面板可查看实际占用。外置硬盘盘符或目录改变时，可尝试重新定位原片，或按旧、新目录校验后重新关联。

后台任务入口可查看任务进度、失败素材，并对支持的任务进行暂停、继续、取消或仅重试失败项。持久任务可在重开库后继续；导入、维护和 Synco 的停止及恢复方式以各自面板为准。

## 常见问题

**素材存在哪里？**

托管原片、版本和整理信息保存在你选择的 `.moriq` 文件夹中；外部引用原片留在原目录。最近打开列表和应用设置保存在系统用户目录，模型包单独安装。

**需要上传照片吗？**

日常整理和已安装模型的推理在本机完成。下载模型需要联网；发送到 Synco 会把交接副本交给兼容的本机程序；打开地图会调用外部地图服务。

**便携包里的文件可以删除吗？**

便携包根目录仅保留 `Moriq Space.exe`、`ai` 和 `codecs`，不附带独立的许可、版权说明文件或目录。相关资料与构建、审计报告保存在包外。请保留完整的解压目录。`codecs` 提供 RAW、视频等媒体组件，`ai` 提供本地模型的运行组件；只保留 `Moriq Space.exe` 会导致相关功能不可用。模型权重由你另外安装，需要腾出模型空间时，请在 AI 模型页卸载对应模型。

**为什么资源库占用与图片大小之和不同？**

版本、交接副本和预览会产生额外占用，共享内容可能通过硬链接减少实际磁盘占用。外部引用登记量也不等于库内占用，以空间面板的分类统计为准。

**图片打不开或视频无法播放怎么办？**

先确认源文件存在、便携包完整，必要的系统解码器已安装。部分相机 RAW、视频编码和超大媒体仍可能不受支持；保留原文件，并记录格式和错误提示以便反馈。

**导入并发设为 10，为什么没有同时处理 10 张？每张都要预留 1024 MiB 吗？**

10 是处理上限，不保证同时解码 10 张。RAW 会先探测元数据，再按尺寸和解码所需缓冲区估算内存，不再每张固定预留 1024 MiB；普通图片也受内存预算约束，视频及部分无法估算的路径仍使用保守预算。大图可能降低实际并发，可结合状态栏峰值、等待内存数和设置中的单张估算判断。

**模型下载失败怎么办？**

在 AI 页“模型设置”中确认下载源。默认使用国内镜像；如该源不可达，可暂停下载、切换“国内下载加速”开关，再点击继续。切换源不需要重建资源库，完整性校验失败的文件需要重新下载。

**能直接管理十万张照片吗？**

大批量导入前，请先备份素材，再分批导入。可以先导入一部分，确认浏览、搜索和导出符合需要后继续；实际速度取决于硬盘、素材尺寸和可用内存。

## 使用范围与反馈

当前建议在 Windows 上使用。部分相机 RAW、视频编码和显卡可能不兼容；遇到问题时，请保留原片，先用少量副本尝试对应功能。

遇到问题，可在[项目仓库](https://github.com/ShanGuoP/Moriq)反馈。请附上系统版本、操作步骤、素材格式和错误信息。诊断日志默认关闭；在设置中开启并重启后，Windows 日志位于 `%LOCALAPPDATA%\MORIQ\logs\desktop.log`。开启后的日志可能包含文件名和路径，分享前请检查内容。
