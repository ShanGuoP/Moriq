# MORIQ 墨屿

给照片、参考图和创作素材一个安静的本地空间。

杉果派 · [项目源码](https://github.com/ShanGuoP/Moriq) · [MIT License](LICENSE)

MORIQ 是一个正在开发的 Rust 原生桌面素材管理器，使用 Iced + wgpu + SQLite，没有 WebView 或 JavaScript 前端。

当前是 **0.1 开发版**：已接入日常管理与 Synco 客户端，仍不是完整产品。

目前已验证 Windows 原生窗口与基础管理流程；macOS、真实十万张素材性能和完整 AI 流程尚未验收。功能说明以真实资源库模式为准，界面中的模型卡片不代表模型已经可安装。

程序统一输出到 `target/`，打包后的入口为 `target/package/MORIQ.exe`。独立设计预览 EXE 已移除。界面使用统一蓝色花形标识，顶部头像已移除。

## 现在可以做什么

- 创建、打开、切换 `.moriq` 资源库；每个库拥有独立数据库和文件锁。
- 导入 JPEG、PNG、WebP、GIF 首帧和 BMP；Windows 可通过已安装系统解码器导入 RAW、TIFF、HEIC/HEIF/AVIF，也可拖入图片。RAW 支持取决于系统编解码器。
- 按项目保留原文件夹和文件名；托管原片或外部引用，按 SHA-256 去重。
- 边扫描边导入；自动选择并发，手动可设 1～32 路及内存预算，数据库统一提交，可安全停止。
- 在瀑布流、固定网格或列表中浏览，调整卡片大小，查看适应窗口预览。
- 按文件名、标签与备注搜索；筛选日期、格式、尺寸、评分、颜色和添加方式。
- 多选及 Shift 范围选择、批量收藏/评分/追加或移除标签/项目归类，保存规则智能集合。
- 项目父子层级、标签重命名/合并/删除、日期区间和全文索引搜索。
- 文件夹或外部引用导入，查看真实 EXIF，备注、回收站恢复、引用原片重定位。
- 导出原文件或 JPEG/PNG/WebP，设置最长边、JPEG 质量和旋转，原片不改写。
- 库外一致性备份，后台完整性检查、缩略图和颜色修复，查看进度、安全停止和中断导入恢复。
- 回收站恢复、所选素材永久删除，以及删除失败还原和重新打开后的恢复。
- 保存封面/描述、最近打开列表；Synco 发送、领取为新版本、去重 ACK 和版本切换。
- 新建项目，在项目内导入图片；目录保留原名，同内容跨项目用硬链接归档，整理关系保存在数据库。
- 查看资源库概览、素材详情和 AI 模型能力说明。
- 会话内前进/后退恢复查询、滚动和选择；详情按当前排序跨页浏览相邻图片。
- 图片双击放大，右键或三个点打开紧凑操作菜单；退出大图回到原图库位置，子面板返回实际入口。
- 标签直接精确筛选，查看真实后台任务；未开放的 AI 分类和模型安装明确禁用。
- 项目/收藏使用 9:16 竖封面，空项目保持独立占位；项目菜单支持改名和内容删除。
- 删除项目时两次确认，移除项目及子项目的独占素材、全部版本和数据库记录；共享素材与外部引用原片保留，失败/重开可恢复。
- 编辑资源库名称与描述，查看真实更新时间、持久项目最近访问、通知未读及可分页活动记录。
- 组合规则支持嵌套全部/任一/排除条件，可保存为智能集合；文字条件参数化，树最多 8 层和 64 节点。
- 补充版本地点或清除后恢复原片 GPS 显示，点击后打开地图；不改写原片或后台查询位置。
- 查看资源库实际分配空间、硬链接去重、托管/引用登记量及卷容量，后台统计可停止。
- 版本页可并排查看两个版本的预览，不改变展示版本；搜索与快捷键帮助可从工具菜单或 F1 打开。

项目卡片的三个点打开该项目的管理面板，永久删除前会列出范围并要求两次确认；不因中断导入、Synco状态、项目数量或确认后内容变化拦截，按执行时的项目内容删除并清理对应中断记录。回收站多选删除仍按每批最多10000项处理。顶部“更多”菜单打开资源库工具；叠层图标进入智能集合。整理、导入、Synco 和备份检查也可从相应面板进入。

日常整理、修图回传和导出不会改写原片；确认永久删除时会删除所选素材的托管原片、库内版本与副本，外部引用原片保留。项目关系、标签、备注和版本记录保存在用户选择的 `.moriq` 文件夹内，关闭应用后可整体复制或移动。

## 工程结构与数据约定

| 模块 | 职责 |
|---|---|
| `apps/desktop` | Windows GUI 入口、启动参数和程序图标构建 |
| `crates/moriq-ui` | Iced 界面、选择与视图状态、异步回执校验 |
| `crates/moriq-app` | 有界任务队列、单库协调与导入/维护服务 |
| `crates/moriq-domain` | 素材、版本、查询与任务数据类型 |
| `crates/moriq-library` | SQLite、文件存储、导入导出、备份与恢复 |
| `crates/moriq-render` | 网格和瀑布流的可见范围与位置索引 |
| `crates/moriq-synco` | 同机 Synco 协议客户端 |

当前数据库 schema 为 v12，已有 v1→v12 迁移。v10 增加活动/通知/库元数据，v11 增加版本地点，v12 提高组合规则最低读取版本以避免旧程序忽略条件。素材身份由数据库中的稳定 ID 关联；托管文件按项目保留原文件夹和原名，同名冲突追加序号。相同内容跨项目可用硬链接归档，不重复复制原片内容。模型包与库内 AI 成果分离是后续实现约定，目前尚无可安装模型包。

## 运行

Windows 开发环境：Rust **1.99.0**、MSVC C++ 构建工具和 Windows SDK。

```powershell
cargo run -p moriq-desktop
```

首次打开时输入库名，再选择保存位置。打开已有库时，选择 `.moriq` **目录**。

开发构建位于 `target/debug/moriq-desktop.exe`；最新打包程序请打开 `target/package/MORIQ.exe`。当前已验证的便携包为 Debug 构建，Release 打包入口见下文。构建产物和测试图库没有提交或上传。

```powershell
# 直接打开指定资源库
cargo run -p moriq-desktop -- --library 'D:\Pictures\我的素材库.moriq'
```

## 当前限制

主要剩余工作：

- **UI 交互**：其余菜单细节、完整设置与快捷键、跨启动历史和窄窗口适配；通知/活动、项目最近访问、地点与空间明细已接通。
- **AI**：模型包清单、主动下载、暂停/续传、安装/卸载、索引保留、六类模型推理及可恢复任务队列；当前主要是能力说明与界面结构。
- **搜索与整理**：独立虚拟文件夹、完整 EXIF/GPS 索引条件、近似重复、人物聚类和相似推荐。精确重复导入去重已经可用。
- **浏览与性能**：原尺寸/区域解码、ICC/HDR、集中 CPU/GPU/磁盘缓存、读取池和帧时采样。当前预览最长边为 1600 像素。
- **格式与可靠性**：视频、SVG/PDF/PSD、跨平台 RAW、源盘离线恢复、克隆/迁移、孤儿文件审计和更多故障注入。
- **发行与验收**：真实十万张正式基线、五十万张独立压力测试、完整英文、Windows 安装器/签名及 macOS 实机验收。

Synco 客户端已经实现，需要先启动具有兼容交接接口的 Synco；当前对接依据为本地 Synco 0.4.1 协议实现。隔离回执/网络测试通过；真实双端精修回传、自动启动、失败后新任务重试及独立交接副本回收还待联调。永久删除所选素材时会清理该素材已结束交接的库内副本。

引用原片保留在原来位置，不包含在 `.moriq` 备份中；外部修改或文件缺失会显示错误并保留记录。完整性检查和缓存修复在后台运行，支持进度与停止。回收站支持所选素材永久删除及中断恢复，保留外部引用原片。

原有中英文资源文件保留，本轮新增界面以简体中文对照实现，英文迁移尚未完成。

Windows 已编译并实际启动。Windows/macOS 的 CI 配置已添加，尚未在远端执行；macOS 实机和发布打包尚未验证。

固定 6000 万像素/30000 单边业务限制已移除，保留内存/输入字节保护；6400 万像素 JPEG 和真实 RW2 导入/预览/导出已验证。点击详情图可放大查看，背景为高斯模糊。预览最长边仍为 1600，不是原尺寸或色彩校准查看；模型安装与内容分类等未接通入口不计为完成。本地逐项接续说明见 `docs/PROJECT_HANDOFF.md`，该文档按要求保留在本地。

## 检查

```powershell
cargo fmt --all --check
cargo clippy --workspace --all-targets --all-features --locked -- -D warnings
cargo test --workspace --locked
```

合成数据库基准需要单独执行：

```powershell
cargo test -p moriq-library synthetic_metadata_benchmark -- --ignored --nocapture
```

这个基准只测 10 万 / 50 万条合成元数据，不代表真实照片加载、GPU 缓存或滚动性能。

最近完整测试运行为 58 项通过、1 项合成基准忽略；之后新增共享路径保护并复跑永久删除测试，累计 59 项测试通过。严格静态检查、Windows 构建、便携 ZIP 内容和程序启动已验证；不等同于真实容量、AI 或 Synco 双端验收。

## 打包与源码范围

```powershell
# 默认构建 Release，输出 EXE 和便携 ZIP
./scripts/package.ps1
# 本地调试打包
./scripts/package.ps1 -Configuration Debug
```

固定输出 `target/package/MORIQ.exe` 和 `target/package/MORIQ-Windows.zip`，再次打包覆盖上一份，不生成设计预览 EXE。当前便携包不含安装器或签名。

Git 保留 Rust 源码、测试源码、构建脚本、Cargo 清单与锁文件、CI 配置及界面必需资源。`target/`、本地 `docs/` 设计稿和开发记录、生成的截图/测试图库、数据库、日志、压缩包及可执行文件均被忽略。测试使用临时目录生成样本，不提交测试数据库或照片库。

历史生成样本已从源码目录移入 `target/local-test-data/`，后续截图放入 `target/test-artifacts/`。源码仓库为 [ShanGuoP/Moriq](https://github.com/ShanGuoP/Moriq)；`target/source-audit.git` 仅是本地忽略规则核验用的隔离仓库。
